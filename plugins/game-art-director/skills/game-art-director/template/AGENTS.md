# Game Art Workspace Instructions

This directory belongs to one game only. Read workspace.json, docs/GDD.md and applicable art style specs.
Keep approved designs and assets unchanged unless the user expressly requests edits.
Keep full-screen design drafts in designs/, independently reusable art resources in assets/, manifests in catalog/, previews in previews/ and outputs in deliverables/.
Never claim generated assets exist unless actual files have been created.
Record updates in docs/worklog and verify file references before delivery.
Only work with authorized project files and model calls.
