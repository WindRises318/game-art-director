# Game Art Director（游戏美术总监）

**面向 Codex 的开源 2D 游戏美术工程标准与 Agent Skill。**

> **v0.1 开发原型**：已有项目初始化、GDD 工作流程、规范模板、资产清单与静态校验；**不自带生图模型，不具备成熟的自动切图、动画或 Cocos Prefab 生成能力**。

## 产品方向

一个游戏对应一个 Art Workspace。用户通过对话下达美术需求、审阅生成成果并提出纠错；Codex 自主检索相关项目文件、规划任务、调用已配置的真实图像工具、维护资产版本并验证交付。

## 当前目标

- 单一入口 `$game-art-director`
- 可复用 `game-art/` 工作区，覆盖 GDD、UI、角色、场景、道具、动画
- JSON Schema 素材规范、静态校验和覆盖率工具
- 保留现有资源、审批、按需检索、版本回滚

## Codex 云端开发

请参阅 [云端指南](docs/CODEX_CLOUD.md) 和 [路线图](docs/ROADMAP.md)。首项工作是确保 GitHub 上全部源码及模板可用，然后实现可配置的图像 Provider 接口与模拟测试，不要自动执行收费图片生成。
